# Dictionary App
A dictionary miniproject I made for CSP2 while learning Python
## Calculations
AverageGDPandGDPpercapita: Takes the average GDP and GDP per capita for each countries cities and then ranks them based on greatest to least
AveragePopulationCountry: Pretty much the same as above except for population and density per km2
RankPopulation: Runs through the dictionary and ranks each city by its population 
## Challenges I Ran Into
I had to look up how to sort a dictionary from greatest to least, which was much more efficient than running a separate for loop. Also, figuring out that list comprehension was the most efficient way to print what I wanted to with conditionals helped me compress my code.
## What I'd Improve With More Time
My main menu is a little clunky and could be smoothened out in order to be more comprehensible and intuitive. Also, I made all the items in my list lowercase to solve for Capital letters, because even though .title() gives you the first letter capitalized, I had the USA as a country, and I wasn't sure that that would apply.
